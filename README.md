# Анормальность

Юрий Клочко. *Книга для тех, кому недостаточно фактов.*

Веб-версия книги: один файл `index.html`; все графики и экраны рисуются на месте, картинок нет.
Внешние зависимости — шрифты Google Fonts и KaTeX (CDN) для формул в свёрнутых блоках.

## Правка текста

Текст глав лежит в `src/edit_prose.py` (одна строка — один абзац; `>> ` — выносная цитата,
`** ` — тезис с маркером; `[SCREEN]`, `[SHEET]`, `[VISUAL]` — места экранов и графиков, не трогать).

```
cd src && python3 rebuild_prose.py
```

пересобирает `index.html`, сохраняя экраны, графики, математику и сноски.
